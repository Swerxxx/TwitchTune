## Обновление существующей программы

1. Закрой старую версию TwitchTune.
2. Распакуй обновление в папку с исходниками (или в отдельную папку для сборки обновлённого EXE).
3. Запусти `build_exe.bat` в папке `TwitchTune`.
4. Новый EXE находится в `dist\TwitchTune\TwitchTune.exe`. Переноси всю папку `dist\TwitchTune`, а не один EXE.

Программа по-прежнему использует `%USERPROFILE%\TwitchTune`: `queue.sqlite3`, `settings.json` и `tracks`. Существующие заявки и пути к скачанным файлам сохраняются; новые поля и профили добавляются в ту же базу автоматически. Перед обновлением можно скопировать эту папку как резервную копию. Две версии одновременно запускать не следует.

## Запуск из исходников

Нужны Python 3.11+ и FFmpeg. Открой папку `TwitchTune` и запусти `run_windows.bat`, либо выполни:

```powershell
py -m pip install -r requirements.txt
py app.py
```

Для сборки EXE дважды щёлкни `build_exe.bat`. Используется `py -m PyInstaller`; отдельная настройка PATH для PyInstaller не нужна. Если EXE сразу закрывается, запусти `run_debug.bat` из `dist\TwitchTune`. Журнал ошибки: `%USERPROFILE%\TwitchTune\startup_error.txt`.

## Подключение Twitch

1. Нажми «Подключить Twitch» и вставь Client ID своего приложения Twitch. Секрет не нужен. Используется Device Code Flow и разрешение `channel:read:redemptions`.
2. Подтверди вход на открывшейся странице; код выводится в журнале приложения.
3. На канале нужна включённая награда Channel Points с обязательным текстовым полем, например «Песня».
4. Выбери эту награду в выпадающем списке. Выбор сохраняется для следующего запуска.

Токены сохраняются через keyring в системном хранилище учётных данных. При ошибке сохранения приложение сообщает об этом в журнале.

## Использование

- Для проверки без Twitch вставь ссылку, при желании укажи ник и нажми «Добавить».
- Двойной щелчок по загруженному треку запускает воспроизведение. Кнопка ▶ / Ⅱ запускает выбранный или первый готовый трек, затем переключает паузу.
- После окончания песни запускается следующий готовый трек по порядку очереди. Если готовых треков нет, воспроизведение останавливается. Новую загрузившуюся песню в этом случае запускай кнопкой ▶ / Ⅱ.
- «Пропустить» относится к играющей песне. «Завершить» исключает выбранную заявку из автоматического воспроизведения. Без оценки она ждёт оценки в очереди; с сохранённой оценкой переходит в историю.
- Выдели заявку, заполни каждый включённый критерий от 1 до 6, напиши комментарий и нажми «Сохранить оценку». При необходимости отключи «Оценивать текст». Общий балл пересчитывается сразу; «—» означает, что ещё не все включённые критерии заполнены. Заявки без ника вручную относятся к профилю «Вручную».
- Вкладка «Профили зрителей» показывает средние баллы. Двойной щелчок по треку в профиле открывает его заявку для просмотра или редактирования оценки.
- Для повторного прослушивания открой «03 История» и дважды щёлкни по треку. «Вернуть в очередь» ставит его в конец очереди, сохраняя прежнюю оценку.

## Источники и ограничения

YouTube и SoundCloud: загрузка доступных записей. Яндекс Музыка: прямая загрузка через собственную авторизованную сессию; версия YouTube выбирается только вручную при необходимости. VK: попытка загрузки доступного источника через yt-dlp. Spotify напрямую не скачивается: приложение предлагает название и поиск версии на YouTube. Для Spotify, Яндекс Музыки и VK доступна кнопка «Найти версию» с ручным подтверждением результата.

Ограничения: один трек, максимум 15 минут и 100 МБ, максимум 100 активных заявок. Плейлисты и трансляции отклоняются. Доступность загрузки зависит от источника и его ограничений.

## Поиск текста песни

Для поиска нужен интернет. Источник: LRCLIB, https://lrclib.net/docs.txt. Регистрация и ключ API не требуются. В запрос передаются исполнитель и название песни; аудио, ник зрителя и токены Twitch не отправляются. Наличие текста зависит от базы и правильного названия.

Кнопка в нижнем плеере сначала показывает «Ищем текст…». При успешном поиске нажми «Текст песни». Если нет результата или произошла ошибка сети, «Найти текст» открывает окно для уточнения/повтора. При неточном совпадении сначала выбери подходящего исполнителя и версию в списке. Если LRCLIB хранит только LRC, временные метки убираются для обычного чтения. Подсветка строк по времени пока не реализована.

Окно не блокирует основной плеер. При смене песни открытое окно сохраняет прежний текст и название; для новой песни нажми кнопку в плеере снова. Окно поддерживает выбранную тему, прокрутку и выделение текста. Найденные результаты кратковременно кешируются в памяти текущего сеанса. Сетевые ошибки и ограничения сервиса не отображаются как «текст отсутствует».

Пройдены 86 офлайн-тестов, отображение окна с собственным демонстрационным текстом и живой запрос поиска к LRCLIB (HTTP 200). Windows-сборка и проверка на пользовательском компьютере по-прежнему выполняются через build_exe.bat.

## Настройка прямой загрузки Яндекса

1. Обнови исходники и собери EXE через build_exe.bat — он установит новый модуль загрузки.
2. Открой music.yandex.ru в своём браузере и войди в аккаунт с подпиской, в котором доступна нужная песня.
3. В TwitchTune выбери **04 Настройки → Яндекс Музыка → Firefox / Chrome / Edge**. По умолчанию источник входа не выбран, браузеры автоматически не читаются.
4. Если браузер не позволяет прочитать сессию (например, из-за блокировки профиля или особенностей шифрования), попробуй закрыть его либо выбери **Файл cookies.txt** и укажи локальный экспорт сессии Яндекса в формате Netscape. Требуется актуальная Session_id для домена Яндекса. Файл не переписывается приложением.
5. Отправь ссылку на один трек или выдели прежнюю неудачную заявку и нажми **Повторить**. Для Яндекса эта кнопка сбрасывает ранее выбранную замену и пробует исходную ссылку.

Используется yt-dlp-yandex-music версии 2026.9.24, отдельный современный экстрактор вместо устаревшего встроенного. Приложение не переключает Яндекс-заявку на YouTube автоматически. Все cookies других сайтов отбрасываются; в settings.json хранятся только название браузера/путь выбранного файла, а не значения cookies. Сессия используется только для загрузки Яндекса.

Защита от неполных записей: ответы preview/smart_preview отклоняются; скачанный MP3/FLAC дополнительно проверяется по фактической длительности. Фрагмент вместо полной песни не становится «Готово». Лимиты 15 минут и 100 МБ сохраняются. Доступ зависит от аккаунта, региона и работы сервиса; свободная загрузка любых треков без входа/подписки не обещается. Полную авторизованную загрузку в среде разработки не выполняли: пользовательская сессия не предоставлялась.

Документация модуля: https://github.com/fgsfds1/yt-dlp-yandex-music-plugin .

## Полностью удалить заявку

Выдели трек в очереди или истории, нажми **Удалить** и подтверди. Запись исчезает из обоих разделов и профиля; оценка/комментарий удаляются, средний балл пересчитывается. Если это была последняя заявка зрителя, пустой профиль удаляется. Повторно доставленное событие Twitch не восстанавливает удалённую заявку.

Файлы удаляются только из собственной папки tracks, включая части незаконченной загрузки. Файлы вне кеша приложения не затрагиваются. При удалении играющего трека плеер останавливает его и переходит к следующему. Если файл занят другой программой, приложение повторяет удаление и сообщает в журнале, если файл всё ещё занят. Загрузка удалённой заявки не может вернуть её в очередь.

Проверено 86 тестов, включая регистрацию современного экстрактора, прямой маршрут по исходному URL, фильтрацию сессии, запрет превью, удаление во время загрузки, удаление играющего трека и пересчёт профилей. Windows EXE и скачивание с реальным аккаунтом требуют проверки на пользовательском компьютере.


## Исправление ошибки запуска yt_dlp_plugins

Если предыдущий EXE завершался с `ModuleNotFoundError: yt_dlp_plugins. Site initialization is disabled`, скачай обновлённый архив, распакуй его целиком и запусти `TwitchTune/build_exe.bat`. После сборки используй `TwitchTune/dist/TwitchTune/TwitchTune.exe`. Переноси всю папку `dist/TwitchTune`, а не только EXE.

Причина — специальный загрузчик плагинов yt-dlp: ему нужны реальные каталоги `yt_dlp_plugins/extractor`, тогда как обычный hidden import помещал модуль только внутрь PYZ. Новый `hooks/hook-yandex_direct.py` добавляет файл закреплённого модуля Яндекса на диск внутри сборки. Оба сценария сборки подключают эту папку hooks. PowerShell также проверяет коды выхода установки и сборки.

## Автоматическая загрузка по ссылке Spotify

## Несколько наград Twitch: до 2, 3 и 4 минут

После входа в Twitch нажми **«Награды»** рядом со списком наград. Отметь все нужные музыкальные награды, поставь каждой лимит **2 / 3 / 4 мин** и нажми **«Сохранить»**. У каждой награды на Twitch должен быть включён обязательный ввод текста. В списке появится «Принимаются награды: 3», а рядом — «Награды (3)». Обычный выбор одной награды в выпадающем списке переключает приём обратно на неё одну.

Все отмеченные награды слушаются одновременно через одно соединение Twitch с отдельной подпиской на каждую. Заявки попадают в общую очередь; у каждой сохраняется собственный лимит и название награды. Лимит виден в строке очереди. Длительность проверяется перед скачиванием, в том числе для замены на YouTube; запись ровно на границе разрешена, длиннее — отклоняется. Если источник не сообщает длительность, заявка с лимитом также не проходит проверку. Настройки сохраняются; старые и ручные заявки получают прежний лимит15мин.

Проверка: попроси зрителя активировать по очереди три награды с разными ссылками. Убедись, что в очереди появляются его ник и соответствующие лимиты. Для награды2мин проверь запись короче2мин и длиннее2мин. Отклонение в TwitchTune не возвращает баллы автоматически — решения по награде и возвраты остаются в Twitch. Код не меняет статусы активаций Twitch и использует прежнее разрешение только на чтение.

## Текст песни из описания SoundCloud

При загрузке SoundCloud-трека программа проверяет его описание. Блок под «Lyrics», «Текст песни», «Текст», а также куплеты с обозначениями Verse/Chorus/Куплет/Припев используются как текст песни. ## Отмена награды Twitch удаляет песню

При активном подключении программа слушает изменения статуса активаций. Если награда отменена в Twitch (status canceled, баллы возвращены), соответствующая заявка удаляется из очереди/истории вместе с оценкой, комментарием, аудио и обложкой. Если трек играет, он останавливается и запускается следующий готовый. Поздняя загрузка или повтор события не восстанавливают заявку. Статус fulfilled не удаляет трек.

Для этого используется прежнее разрешение channel:read:redemptions; программа не возвращает баллы сама и не меняет статус награды в Twitch. События учитываются только при подключённом TwitchTune. Отмены, совершённые при закрытом приложении или потерянные во время разрыва соединения, автоматически задним числом не сверяются.

## VIP TwitchTune: три приоритетных трека

Во вкладке «Зрители» выбери профиль → «Выдать VIP». Если зритель ещё не присылал треки, нажми «VIP по нику» и введи его Twitch-ник. Это внутренний статус TwitchTune: он не выдаёт VIP-роль в чате Twitch.

Первые три новые принятые заявки такого зрителя перемещаются выше обычных, сохраняя порядок среди уже добавленных VIP-треков. Текущая песня не прерывается. Четвёртая и последующие идут в обычную очередь. В профиле видно, сколько осталось: VIP3/3…0/3; приоритетные строки помечаются VIP★. Лимиты наград2/3/4мин продолжают действовать.

## Резервные источники текста песни

Автоматический поиск и кнопка «Найти» используют общий LyricsResolver. Для ссылки Яндекс Музыки: текст оригинального трека из Яндекса → LRCLIB → Genius. Для других ссылок: LRCLIB → Genius; найденный текст в описании SoundCloud по-прежнему имеет приоритет. При ошибке, перегрузке или отсутствии текста программа переходит к следующему источнику. Если LRCLIB вернул лишь возможные совпадения, Genius также проверяется; неточные версии выбираются вручную.

Яндекс использует только источник входа, выбранный в настройках Яндекс Музыки. При отсутствии доступного текста/прав/подходящего входа поиск продолжается на других сервисах. При ручной смене названия/исполнителя оригинальный ID Яндекса не используется для другой песни. Genius получает только поисковые слова, без cookies Яндекса. Программа не обходит проверки доступа сайтов. В окне текста и списке версий отображается источник; тайминги скрыты.

Кеш не переносится между запусками. Доступность текста зависит от источника; получение текста для каждого трека не гарантируется.

Проверено164офлайн-тестами: fallback при ошибках/перегрузке/пустом ответе, отдельные источники, очистка разметки, кеш, отмена устаревших запросов и подключение к интерфейсу. Реальные Genius/Яндекс-сессия пользователя и Windows EXE здесь не проверялись. Для обновления распакуйте исходники и заново выполните build_exe.bat; данные приложения в домашней папке сохраняются.


## Обновлённое окно наград и точность до секунды

«Награды» открывает окно с карточками в выбранной теме ACID DECK: название награды, стоимость в баллах, подсветка включённых наград и счётчик выбранных. Неотмеченные карточки не принимают заказы; их длительность недоступна до включения. Длинный список прокручивается, кнопки сохранения и отмены остаются внизу. Сохранение без выбранных наград недоступно, как и прежде.

В каждой карточке — отдельные поля «мин» и «сек». Число можно ввести, изменить стрелками поля, клавишами ↑/↓ или колесом мыши. Например, 02 мин 30 сек задаёт лимит150секунд. Допустимо от00мин01сек до15мин00сек; при15минутах секунды ограничены нулём. Существующие лимиты восстанавливаются без округления. Значения по-прежнему хранятся в секундах, применяются индивидуально к новым заказам и полностью отображаются в подсказке списка наград и журнале. Сохранённые заказы сохраняют свой прежний лимит.

169офлайн-тестов прошли, включая точность сохранения, ввод с клавиатуры, границы, передачу лимита в заявку и фильтрацию длительности. Окно визуально проверено в зелёной/фиолетовой/чёрной/красной темах и в минимальном размере; REWARDS_PREVIEW.png — синтетический пример. Windows EXE здесь не собран. Обновление: распаковать исходники, выполнить build_exe.bat, затем запускать dist\TwitchTune\TwitchTune.exe. Данные хранятся отдельно в домашней папке TwitchTune.

## Исправление проверки входа VK (Firefox)

## Оценка по критериям — 04.11.2026

В существующем TwitchTune заменён ввод общей оценки на пять критериев: текст, бит, флоу, вайб, сведение / мастеринг. Каждый оценивается целым числом 1–6. Переключатель «Оценивать текст» исключает текст из расчёта и позволяет вернуть его прежнее значение до сохранения/при редактировании. Максимум одинаковый в обоих режимах: 66.

С текстом: итог = округление(66 × сумма / 30); без текста: округление(66 × сумма / 24). Округляется только конечный результат до ближайшего целого, .5 вверх, без ошибок float. Все 1 → 11, все 4 → 44, все 6 → 66. До заполнения всех включённых критериев кнопка сохранения неактивна. У каждого критерия одинаковый вес.

Хранятся итог, шкала, каждый критерий, флаг включения текста и комментарий. Новые поля queue.rating_scale (DEFAULT 10), queue.rating_details (JSON, version=1); новая запись через QueueStore.rate_criteria. ratings.py — расчёт и форматирование без Qt. Legacy QueueStore.rate оставлен для совместимости. Старые оценки /10 сохранены без придумывания критериев и без автоматического пересчёта. profiles.average содержит только прежние /10; profiles.average66 — новые /66. В интерфейсе показываются отдельно. Итог трека всегда целый; средние профиля могут иметь дробную часть.

Черновик критериев/переключателя/комментария сохраняется при фоновом обновлении очереди и переходе выбранного трека в историю; выбор другой заявки загружает её собственную оценку. Критерии видны в профиле и подсказке заявки. В компактном окне декоративный дисплей скрыт, чтобы панель оценивания оставалась читаемой; плеер внизу сохранён. Все темы поддерживаются.
