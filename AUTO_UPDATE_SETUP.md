# Обновления готового TwitchTune для Windows

Получатель один раз получает новую папку с EXE, в который уже встроен обновлятор. Затем открывает «Настройки → Обновления приложения → Скачать и обновить». Python, перенос файлов и повторный build на его компьютере не нужны.

При запуске готовой версии программа проверяет настроенный канал. Установка начинается после согласия пользователя. Если играет песня, автоматическое предложение не прерывает её: обновление остаётся доступно в настройках.

## Что подготовлено

- Проверка номера версии и загрузка по HTTPS.
- Проверка размера, SHA-256 и структуры архива до закрытия приложения.
- Отдельный PowerShell-процесс заменяет EXE и `_internal` после завершения TwitchTune, затем запускает новую версию.
- Проверка запуска и возврат прежних файлов программы при ошибке запуска. Профиль не откатывается: будущие миграции базы должны сохранять совместимость.
- Очередь, музыка, оценки и настройки остаются в `%USERPROFILE%\TwitchTune`. Посторонние файлы в папке установки не заменяются.
- Windows-сборка и выпуск релиза подготовлены в `.github/workflows/windows-release.yml`.

Канал обновлений: `https://github.com/Swerxxx/TwitchTune/releases/latest/download/latest.json`. При изменении `release_version.py` в ветке `main` автоматически запускаются Windows-сборка и проверки перед публикацией. Первый релиз станет доступен после успешного завершения Actions.

## Первый выпуск автором

1. Выбери GitHub-репозиторий. Приведённый workflow рассчитан на публичный репозиторий: исходники и релизы в нём будут доступны всем. Не публикуй личный профиль, cookies или ключи. Для закрытых исходников потребуется отдельно настроить публичный канал файлов.
2. Загрузи **содержимое папки `TwitchTune`** из полного архива в корень репозитория. В корне должны лежать `app.py`, `requirements.txt`, `tools` и `.github`, без дополнительной внешней папки `TwitchTune`. Нужен полный архив, не Clean.
3. Открой **Actions → Windows release → Run workflow**. Укажи первый номер, например `1.0.0`.
4. Дождись успешного завершения сборки, тестов, запуска EXE и проверки установки/отката. Только после этого workflow публикует релиз с `TwitchTune-Windows-x64.zip` и `latest.json`.
5. Скачай ZIP из Releases. Передай получателю всю распакованную папку `TwitchTune`; запускать нужно `TwitchTune.exe` внутри неё. Устанавливать в `Program Files` не нужно: папка программы и её родитель должны быть доступны пользователю для записи.
6. Закрой прежнюю программу перед первым переходом. Не удаляй `%USERPROFILE%\TwitchTune`: новая версия читает прежнюю очередь и настройки оттуда. Старый EXE без обновлятора сам получить эту возможность не может.

Workflow сам записывает номер версии и адрес `https://github.com/OWNER/REPO/releases/latest/download/latest.json` перед сборкой. Пароль или персональный GitHub-токен в программу не попадает. Для публикации CI использует стандартный токен GitHub Actions.

## Следующие версии

Внеси изменения в тот же репозиторий и снова запусти **Windows release** с большим номером, например `1.0.1`, затем `1.0.2`. Также можно отправить тег `v1.0.1`. Один номер не переиспользуется. Не меняй имя и адрес канала без отдельного перехода для установленных клиентов.

После успешной публикации получатель нажимает «Проверить обновления», затем «Скачать и обновить». Приложение скачает пакет, закроется и запустит новую версию. Обновление требует интернета и временного свободного места для архива, новой версии и резервной копии.

При сбое смотри `%USERPROFILE%\TwitchTune\updates\last-result.json` и журнал `installer.log` в подпапке обновления. Резервная папка `.TwitchTune-backup-…` находится рядом с установленной программой. Проверка SHA-256 защищает от повреждённой загрузки; цифровая подпись издателя пока не добавлена.

## Если TwitchTune запускается из исходников

Для него остаётся `TwitchTune-Update.bat` и прежний быстрый запуск с Python. Этот маленький установщик не обновляет готовый EXE. Настройка интернет-обновлений выше предназначена для Windows EXE-сборок.
