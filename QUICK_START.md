# Быстрый запуск и обновление TwitchTune

## Переход с прежней версии

1. Закрой TwitchTune и дождись закрытия окна: загрузки и подключения должны завершиться.
2. Открой небольшой файл **TwitchTune-Update.bat**. Если скачан ZIP, извлеки этот единственный BAT в любое место, например в «Загрузки». Переносить его в программу не нужно.
3. При первом запуске выбери прежнюю папку исходников TwitchTune: в ней находятся **app.py** и **build_exe.bat**. Не выбирай `dist/TwitchTune` с одним EXE.
4. Установщик сам заменит файлы программы, проверит зависимости, создаст ярлыки **TwitchTune** и **TwitchTune Update** на рабочем столе и запустит приложение. Папка запомнится для следующих небольших установщиков.

Python уже должен быть установлен с командой `py`: он использовался при прежней сборке. При первом быстром запуске нужна сеть для проверки/установки зависимостей. Последующие запуски не вызывают pip, пока список зависимостей не изменится. Процесс установки не собирает EXE.

## Обычный запуск

Используй новый ярлык **TwitchTune**. Это та же программа, запущенная из исходников через Python без консольного окна. Также доступен **run_windows.bat**; он может показывать консоль. Старый EXE в `dist` не обновляется этим способом: его ярлык может открывать прежнюю версию.

Если обновляешься полным архивом вручную, достаточно один раз запустить **setup_shortcuts.bat** из папки исходников: он создаст те же ярлыки и откроет приложение.

## Следующие обновления

Есть два пути:

- Получить новый небольшой **TwitchTune-Update.bat** и открыть его. Папка уже запомнена: файлы установятся автоматически, затем откроется программа.
- Скачать новый полный ZIP, закрыть TwitchTune, открыть ярлык **TwitchTune Update**, выбрать ZIP. Он сам установит версию в прежнюю папку и запустит приложение. Распаковывать/переносить исходники и запускать build не требуется. Также можно перетащить ZIP на **update_windows.bat**.

Для описанного здесь режима исходников скачивание ручное: ярлык читает выбранный ZIP. Для готового EXE теперь подготовлен отдельный интернет-обновлятор; его активация и первый выпуск описаны в AUTO_UPDATE_SETUP.md. Канал ещё не настроен.

## Сохранение данных

Очередь, оценки, аккаунты, настройки и музыка по-прежнему находятся в `%USERPROFILE%\TwitchTune`. Обновление их не заменяет. Из архива берутся только файлы исходников, скрипты и ресурсы приложения; чужие JSON/базы и окружение Python не копируются.

Новые запуски и обновлятор используют общую блокировку, поэтому обновление при открытом новом TwitchTune запрещено. Перед первой установкой старый EXE нужно закрыть самостоятельно. До копирования создаётся резервная копия заменяемых файлов в `%USERPROFILE%\TwitchTune\update-backups`; при ошибке замены уже заменённые файлы восстанавливаются. Ошибка последующей установки зависимостей записывается в журнал и требует исправить доступ к сети/зависимостям; данные очереди не затрагиваются.

Журналы: `%USERPROFILE%\TwitchTune\launcher.log` и, при ошибке небольшого установщика, `quick-update-error.txt`. Список зависимостей можно проверить заново командой `py desktop_launcher.py --repair` из папки исходников.

## Передача другому человеку

Прежние **build_exe.bat** и **build_exe.ps1** остаются. Для человека без Python собери и передай всю `dist/TwitchTune`, как раньше. Небольшой установщик предназначен для существующей папки исходников на компьютере с Python и не обновляет готовый EXE.

## Проверка

Логика обновления проверяется офлайн: сохранение данных, архив обычной/чистой версии, блокировка открытой программы, резервная копия/откат при сбое, недопустимые пути и ссылки за пределы установки, установка зависимостей только при изменении списка, целостность маленького установщика и сохранение пути установки. Нативные окна Windows и создание ярлыков в этой Linux-среде не запускались.


## Тексты SoundCloud

В окне текста кнопка «Описание SoundCloud» повторно получает полное описание исходного трека без скачивания аудио. Если отдельный текст не распознан, описание показывается автоматически с соответствующей пометкой. Ранее пустые проверки перечитываются. Для поиска других источников доступно «Уточнить поиск».


## Окончание трека

После окончания песни плеер останавливается. Следующий заказ включается вручную кнопкой⏭ или выбором в очереди. Внутри альбома песни идут последовательно, после альбома плеер также останавливается. Кнопка пропуска во время воспроизведения по-прежнему переключает на следующий заказ.


## Длинные записи

Обычные ссылки и локальные MP3 поддерживаются до90минут включительно, максимальный файл512МБ. Для Twitch-наград действуют их собственные лимиты: до2/3/4минут, если так настроено. В окне наград можно задать до90минут. После обновления старую неудачную обычную заявку можно загрузить кнопкой «Повторить».


## Если Genius недоступен

Поиск проверяет LRCLIB, Lyrics.ovh и Genius, а для Яндекса — его собственный источник. SoundCloudописание остаётся доступным отдельно. Найденные после обновления тексты сохраняются на диске и открываются после перезапуска без повторного обращения к сервисам. «Уточнить поиск → Найти» проверяет заново; при ошибке уже показанный текст не стирается. Пометка «сохранённый текст» означает локальную копию. Отсутствие текста во всех доступных каталогах по-прежнему возможно.


## Обновления готового EXE — текущая подготовка

Добавлены «Настройки → Обновления приложения», проверка версии, загрузка HTTPS с SHA-256, отдельная установка после закрытия и перезапуск. Подготовлены Windows CI-сборка и проверка отката. Подробная настройка автора: AUTO_UPDATE_SETUP.md.

Канал пока не настроен, Windows-релиз ещё не опубликован. Для включения нужен репозиторий с публично доступными файлами релизов. Получателю потребуется один раз передать новую сборку с обновлятором; после этого следующие версии устанавливаются из программы без Python и build. Маленький BAT остаётся способом обновления исходников и не обновляет старый EXE.
