# TwitchTune — расширение очереди заказов (тестовая версия)

После естественного конца трека и сохранения оценки TwitchTune готовит подтверждение. Для альбома нужно дождаться конца последнего трека и оценить альбом целиком. Пропуск не закрывает заказ.

Расширение нажимает кнопку только в карточке с точным ID заказа. Совпадения по похожему названию, нику или позиции недостаточно. Нажатие само по себе не считается успешным: программа ждёт событие FULFILLED от Twitch.

**Ограничение тестовой версии:** совместимость с реальной очередью зависит от разметки страницы Twitch. Если расширение не найдёт точный ID заявки, автоподтверждение остановится.

## Старые заказы

Заказы, уже находящиеся в TwitchTune, обрабатываются после естественного конца воспроизведения и сохранения оценки. Если в старой записи не сохранился ID награды, расширение восстановит связь по точному ID самого заказа, когда эта карточка видна в очереди подключённого канала. Повторное прослушивание и оценка для уже готовой заявки не требуются.

Если заказ есть только в Twitch, откройте нужную страницу очереди и нажмите «Импортировать старые заказы» в расширении. TwitchTune принимает заказы по выбранным в программе наградам. Для импорта нужны точные ID заявки и награды в данных страницы. При необходимости откройте следующую страницу или категорию очереди и повторите импорт. Повторный импорт не создаёт дубликаты.

## Chrome / Edge — установка для теста

1. Установите Windows-сборку TwitchTune с расширением браузера.
2. В TwitchTune подключите Twitch под аккаунтом стримера.
3. Настройки → «Выполнение заказов Twitch · Расширение» → выберите браузер → «Подключить расширение».
4. Нажмите «Открыть файлы расширения».
5. Откройте chrome://extensions или edge://extensions, включите режим разработчика и выберите «Загрузить распакованное расширение». Укажите открытую папку chromium.
6. Включите «Подтверждать заказы через расширение браузера» в TwitchTune.
7. Нажмите «Открыть очередь Twitch» в программе. Войдите в Twitch в этом браузере. Оставьте одну вкладку очереди открытой.
8. При наличии тестового заказа откройте расширение → «Настроить страницу очереди».
9. По подсказкам выберите ник, название награды, текст заявки и кнопку выполнения в одной карточке. При настройке нажатие кнопки перехватывается и заказ не закрывается.
10. Если страница распознана, включите автоподтверждение в расширении. Проверьте на одном тестовом заказе: до конца воспроизведения и оценки он должен оставаться открытым.

## Firefox — временная установка для проверки

1. Выберите Firefox в настройках TwitchTune и нажмите «Подключить расширение».
2. Откройте about:debugging#/runtime/this-firefox → «Загрузить временное дополнение».
3. Выберите `_internal/assets/browser-extension/firefox/manifest.json` в распакованной сборке.
4. Далее следуйте пунктам 6–10 выше.

В обычном Firefox неподписанное дополнение устанавливается временно и удаляется при закрытии браузера. Для постоянной установки требуется подпись Mozilla; она пока не получена.

## Если заказ не закрывается

- Программа и вкладка очереди должны оставаться открытыми. Выбранный канал должен совпадать с подключённым в программе.
- Сначала дождитесь конца трека, затем сохраните оценку (допустим и обратный порядок).
- Сообщение об отсутствии ID означает, что автоматизация остановлена. Не пытайтесь заменять поиск ID совпадением по позиции карточки.
- «Ждём подтверждения Twitch» означает, что нажатие отправлено, но событие FULFILLED ещё не получено. Автоматически повторять такое нажатие программа не будет. Проверьте страницу вручную и соединение TwitchTune с Twitch.
- «Повторить заблокированные задания» применяйте после устранения проблемы разметки/прав. Оно не повторяет уже отправленные нажатия.
- Если страница изменилась, настройте её заново. Массовые кнопки «Выполнить все» не поддерживаются.

## Связь и данные

Обмен идёт через Native Messaging на этом компьютере. HTTP-сервер не запускается. Пароли, cookies и токены браузера не считываются. Дополнение допускается к локальному мосту по своему ID. Перед нажатием перепроверяются канал, ID и актуальность задания. При выключении программы её разрешение истекает; подтверждения сохраняются в локальной очереди.

Настройка Native Messaging производится для текущего пользователя Windows и не требует ручного редактирования реестра. Для отключения выключите функцию в программе и расширении. Удаление расширения из браузера не удаляет очередь TwitchTune.

## Проверка разработчиком

- `python -m unittest discover -s tests`
- `node tests/test_extension_matcher.cjs`
- `node tests/browser_extension_dom.cjs` (требуется Playwright и Chromium)

Сборка Windows: build_exe.ps1 включает TwitchTuneBridge.exe и файлы расширения. В исходниках native host использует установленный Python; обычная Windows-сборка его не требует.
